# Context Kit

Turn an early-stage coding request into a clear, reusable brief. Context Kit runs in your browser; your brief is not sent to an AI service or API.

## Use it

Open [index.html](index.html) in a browser. Add the task, relevant project context, constraints, and acceptance checks. The Markdown brief updates as you type; use **Copy brief** to copy it.

## Features

- Live Markdown preview
- Example brief to get started
- One-click copy and reset
- Responsive layout
- No JavaScript dependencies or account required

## Development

The app is plain HTML, CSS, and JavaScript. Open `index.html` directly or serve the project with any static file server.
